# 작업 카드

단계 종료·상태 변경 때 관련 행만 짧게 출력한다. 시연에서는 시작 시 가상임을 밝히고 분기 변경 때만 다시 설명한다.

| 항목 | 현재 상태 |
| --- | --- |
| 모드·분기 | 실제 상담/사용법 시연 · 본 흐름/분기 ID |
| 지원자·지원 건 | 지원자 ID · 지원 ID · 목표 |
| 이번 결과물 | 파일/본문 버전 · 완료한 범위 |
| 근거 | 가상 설정/사용자 진술/원문 대조/파일 검수 · 출처·범위 |
| 완료 수준 | 초안 / 사실 대조 / 형식·분량 검수 / 제출 준비 각각 완료·미완료·해당 없음 |
| 실제 진행 | 접수·면접·결과는 확인된 상태만 |
| 남은 확인 | 누락·충돌·읽지 못한 자료 |
| 다음 행동 | 1~3개, 기한이 있으면 확정/권장 구분 |

자료 읽기 성공은 사실 진실성의 외부 검증이 아니다. 본 흐름은 유지하며 가상 합격·입사 비교는 별도 분기로만 기록한다. 시연 종료와 제출 준비 완료를 혼동하지 않는다.
