# 작업물과 포트폴리오

## 입력과 선정
공고의 제출 형식·페이지/용량 제한을 먼저 확인하라. 원본 이미지·PDF·작업 파일과 제작 목적·본인 역할·검토 과정·공개 가능 범위를 받되 한 번에 최대 3개만 질문하라. 파일이 없어도 구성과 설명 초안은 제공하고 이미지 품질 평가는 보류하라.
대표 작업물은 직무 관련성, 본인 기여 설명 가능성, 공개 가능 여부로 선정하라. 팀 작업·템플릿·외부 자산을 전부 본인 제작으로 표현하지 마라. 외부 자산의 사용 권한은 확인된 범위만 말하라.

## 작성
1. 작업 개요: 목적, 대상, 기간(확인 시), 도구, 본인·협업자 역할을 구분하라.
2. 전체 흐름: 실제 파일 순서대로 배치하라. 설명만 보고 페이지별 내용을 창작하지 마라.
3. 대표 화면: 실제 관찰한 구성과 사용자가 설명한 선택 이유를 구분하라. '가독성·전환율 향상'을 근거 없이 쓰지 마라.
4. 과정: 전달받은 자료 → 본인 행동 → 검토·수정 → 게시/납품 여부를 확인하라. 확정된 성과가 없으면 산출물과 과정을 보여줘라. 단순 부재를 제출 본문에서 반복할 필요는 없다.
5. 구성만 요청하면 구성까지만, PDF 제작을 요청하면 관련 PDF/문서 스킬로 실제 파일을 만들고 렌더링해 검수하라. 페이지 수는 제안이며 기업 제한으로 오인시키지 마라.

## 검수와 변경
원본 제작물과 새 설명 페이지를 구분하라. 원본을 무단으로 개선해 과거 제작물처럼 보이게 하지 마라. 수정 제안·승인 범위를 따르고, 리디자인이면 새 작업임을 표시하라.
실제 파일에서 정보·오탈자·순서·글자 크기·대비·잘림·해상도·개인정보 노출·페이지/용량 제한을 확인하라. 읽지 못한 부분은 판독 필요로 남기고 범위를 보고하라. 이미지가 없는 문서도 텍스트 설명 초안으로는 쓸 수 있지만 시각 검수 완료로 부르지 마라.
이력서·자소서와 기간·역할·작업 수·성과 표현을 교차 대조하라. 출처·파일 버전·검수 범위를 작업 카드에 기록하라. 필수 원본·자리표시자·사용 권한 확인이 남아 있으면 제출 준비 미완료로 표시하라.
