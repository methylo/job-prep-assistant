# 공고 분석 기준

## 공고 유형 먼저 가른다

| 유형 | 특징 | 추출 방법 |
| --- | --- | --- |
| 공공형 | 공공기관·지자체. 공고문 본문과 별첨 직무기술서로 나뉜다 | 직무기술서 5항목(직무수행내용·필요지식·필요기술·직업기초능력·관련자격)을 그대로 옮긴다. 별첨이 없으면 사용자에게 요청한다 |
| 민간형 | 중소기업·채용 사이트. 담당업무·자격요건·우대사항 서술형 | 서술 문장을 5항목 틀로 옮긴다. 공고에 없는 항목은 "공고 미기재"로 둔다 |

공고에 없는 항목을 채워 넣으면 사용자가 그 내용을 사실로 믿고 서류를 쓴다. 비워 두는 편이 안전하다.

## 출력 표

```
[기본] 지원 ID·기업·직무·고용형태·근무지·근무시간·급여·마감일/시각/시간대·전형 절차
[제출] 서류·문항·글자 수/계수 기준·파일 형식·접수 경로
[근거] 공고 출처·확인일·원문 위치·판독/누락 상태
[직무수행내용]
[필요지식]
[필요기술]
[직업기초능력]
[관련자격]
[자격요건]  ← 미충족·부분충족 시 해당 항목을 밝히고 지원 전 확인
[우대사항]  ← 미충족 시 보완 과제
[공고 근거 추가 확인사항] 1~3개
```

## 자격요건과 우대사항을 가르는 기준

| 표현 | 분류 |
| --- | --- |
| ~자, ~가능자, ~필수, ~이상, 유효 기간 | 자격요건 |
| 우대, 선호, 있으면 좋음, 가점 | 우대사항 |
| 분류가 모호한 표현 | 필수·우대 분류 미확인으로 별도 표시하고 원문 또는 기업에 확인 |

## 공고 근거 추가 확인사항

공고 문장 뒤에 있는 확인 포인트를 근거가 있을 때 최대 3개 적는다. 해석은 명시 요건과 구분하고 가설로 표시한다. 근거가 없으면 생략한다. 근거 없는 추측은 넣지 않고, 어느 문장에서 읽었는지 함께 적는다.

- 채용 인원 1명 + 담당업무 여러 개 → 역할 범위와 기존 팀의 분담을 확인한다. 혼자 전부 수행한다고 단정하지 않는다
- "출퇴근 가능자" 명시 → 통근 가능 여부를 확인한다. 상세 주소·교통 수단을 불필요하게 요구하지 않는다
- "경력 무관"과 우대사항에 경력 항목이 함께 있음 → 신입 지원 가능, 경력 우대가 명시되어 있다. 실제 지원자 구성은 알 수 없다
- 마감일이 상시·채용 시 마감 → 현재 모집 여부를 먼저 확인한다. 조기 지원의 유불리를 보장하지 않는다

## 적합도 판정 4분류

| 분류 | 기준 |
| --- | --- |
| 충족 | 프로필에 해당 경험·자격이 있고 근거 항목을 댈 수 있다 |
| 부분충족 | 비슷한 일을 했으나 공고의 범위·도구·규모가 다르다 |
| 미충족 | 미보유·미경험 또는 확인된 수준·조건이 요건에 미달함 |
| 정보 없음 | 사용자가 아직 말하지 않았다. 묻고 판정한다. 미충족으로 적지 않는다 |

## 도구·자격 요건 수준 가르기

아래는 확인 질문용 참고 기준이다. 공고에 명시된 실제 작업·기업 설명을 우선하며, 일률적인 숙련도 기준이나 자동 탈락 규칙으로 쓰지 않는다.

| 공고 표현 | 요구 수준 | 판정 기준 |
| --- | --- | --- |
| 활용 가능, 사용 가능, 기본 | 실제 요구 작업 확인 | 공고가 그 작업을 명시했고 경험이 확인되면 충족. 표현만 있으면 기업 수준 확인 |
| 능숙, 숙련, 고급 | 실제 요구 작업 확인 | 특정 함수 미경험만으로 미달 판정하지 말고 공고 범위와 대조 |
| 자격증 소지자 | 자격 보유 | 미보유가 확인되면 미충족, 보유 여부 미제공이면 정보 없음. 취득 기한·일정은 공식 정보로 확인한다 |

사용자가 "조금 한다"처럼 답하면 해 본 작업을 물어 판정한다. 수준을 올려 적으면 입사 후 업무에서 드러난다.

부분충족은 서류에서 대체 서술로 살릴 수 있다. 예: 전표 입력 경험은 없고 지출 내역 엑셀 입력 경험이 있을 때, 전표라고 쓰지 않고 "지출 자료를 엑셀로 관리"로 적는다. 공고 단어를 그대로 쓰면 경험을 부풀린 서술이 되어 면접에서 어긋난다.

## 지원 판단과 우선순위
- 필수요건에 정보 없음이 있으면 `판정 보류 — 확인 후 확정`, 확인된 미달도 함께 표시하라. 어떤 답을 받으면 판정이 달라지는지 설명하라.
- 필수요건 부분충족·미충족은 `지원 전 확인`, 모두 충족하면 `요건 기준 지원 권장`으로 표시하라. 우대사항 미충족은 지원 불가 사유가 아니다. 보완 과제 1~3개에 마감 전 가능 여부를 적어라. 자격 취득 등을 단기간 가능하다고 가정하지 마라.
- 별도 표로 희망 필수·선호·제외 조건을 `일치 / 불일치 / 미확인`으로 대조하라. 필수 조건과 충돌하면 요건을 충족해도 우선 지원으로 추천하지 마라. 조건 변경은 사용자가 결정한다.
- 여러 공고는 필수 조건, 요건 근거, 마감, 준비 부담, 경력 방향을 비교해 `우선 준비 / 확인 후 결정 / 후순위 제안`으로 정리하라. 점수·백분율을 만들지 마라. 정보가 부족하면 순위를 확정하지 마라.
- 기업 평판은 출처·시점을 기록하고 공식 정보와 후기를 구분하라. 회사명만으로 좋은 회사라고 평가하지 마라.
