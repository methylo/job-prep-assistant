# 공고 분석 기준

## 공고 유형 먼저 가른다

| 유형 | 특징 | 추출 방법 |
| --- | --- | --- |
| 공공형 | 공공기관·지자체. 공고문 본문과 별첨 직무기술서로 나뉜다 | 직무기술서 5항목(직무수행내용·필요지식·필요기술·직업기초능력·관련자격)을 그대로 옮긴다. 별첨이 없으면 사용자에게 요청한다 |
| 민간형 | 중소기업·채용 사이트. 담당업무·자격요건·우대사항 서술형 | 서술 문장을 5항목 틀로 옮긴다. 공고에 없는 항목은 "공고 미기재"로 둔다 |

공고에 없는 항목을 채워 넣으면 사용자가 그 내용을 사실로 믿고 서류를 쓴다. 비워 두는 편이 안전하다.

## 출력 표

```
[기본] 기업·직무·고용형태·근무지·마감일·전형 절차
[직무수행내용]
[필요지식]
[필요기술]
[직업기초능력]
[관련자격]
[자격요건]  ← 미충족 시 지원 불가
[우대사항]  ← 미충족 시 보완 과제
[숨은 요구] 1~3개
```

## 자격요건과 우대사항을 가르는 기준

| 표현 | 분류 |
| --- | --- |
| ~자, ~가능자, ~필수, ~이상, 유효 기간 | 자격요건 |
| 우대, 선호, 있으면 좋음, 가점 | 우대사항 |
| 분류가 모호한 표현 | 자격요건으로 보고 "확인 필요" 표시 |

## 숨은 요구 읽기

공고 문장 뒤에 있는 조건을 1~3개만 적는다. 근거 없는 추측은 넣지 않고, 어느 문장에서 읽었는지 함께 적는다.

- 채용 인원 1명 + 담당업무 여러 개 → 혼자 여러 일을 처리할 사람을 찾는다
- "출퇴근 가능자" 명시 → 통근 거리와 교통 수단을 서류에서 먼저 밝히는 편이 유리하다
- "경력 무관"과 우대사항에 경력 항목이 함께 있음 → 신입 지원 가능, 경력자와 같이 심사된다
- 마감일이 상시·채용 시 마감 → 빨리 접수하는 쪽이 유리하다

## 적합도 판정 4분류

| 분류 | 기준 |
| --- | --- |
| 충족 | 프로필에 해당 경험·자격이 있고 근거 항목을 댈 수 있다 |
| 부분충족 | 비슷한 일을 했으나 공고의 범위·도구·규모가 다르다 |
| 미충족 | 프로필에 근거가 없다 |
| 정보 없음 | 사용자가 아직 말하지 않았다. 묻고 판정한다. 미충족으로 적지 않는다 |

## 도구·자격 요건 수준 가르기

| 공고 표현 | 요구 수준 | 판정 기준 |
| --- | --- | --- |
| 활용 가능, 사용 가능, 기본 | 입력·정렬·기본 수식 | 그 작업을 해 봤으면 충족 |
| 능숙, 숙련, 고급 | 함수·피벗테이블·양식 제작 | 함수·피벗테이블 경험이 없으면 부분충족 |
| 자격증 소지자 | 자격 보유 | 보유 아니면 미충족. 마감 전 취득 가능 여부를 함께 적는다 |

사용자가 "조금 한다"처럼 답하면 해 본 작업을 물어 판정한다. 수준을 올려 적으면 입사 후 업무에서 드러난다.

부분충족은 서류에서 대체 서술로 살릴 수 있다. 예: 전표 입력 경험은 없고 지출 내역 엑셀 입력 경험이 있을 때, 전표라고 쓰지 않고 "지출 자료를 엑셀로 관리"로 적는다. 공고 단어를 그대로 쓰면 경험을 부풀린 서술이 되어 면접에서 어긋난다.
